# Aero Shell — конфиг Quickshell для Niri

Оболочка в стиле Frutiger Aero / Windows 7: вертикальная стеклянная панель слева, тосты уведомлений, центр управления, менеджер обоев с живыми обоями через `mpvpaper` и палитра, которая подстраивается под текущие обои.

## Требования

| Компонент | Минимальная версия | Зачем |
|---|---|---|
| Niri | 26.04 | blur за панелями (`ext-background-effect`) |
| Quickshell | 0.3.0 | `BackgroundEffect.blurRegion` |
| Qt | 6.9 | `RectangularShadow` (свечение) |
| matugen | 4.x (работает и с 3.x) | генерация палитры |

На более старом Niri или Quickshell оболочка запустится, но стекло будет без размытия.

## Зависимости

```bash
yay -S --needed quickshell niri rofi cliphist wl-clipboard mpvpaper mpv matugen ffmpeg ffmpegthumbnailer pipewire wireplumber ttf-nerd-fonts-symbols noto-fonts
```

Команда через `yay`, потому что часть пакетов может лежать в AUR, а не в официальных репозиториях (я не проверял, где сейчас находятся `mpvpaper` и `matugen`).

## Установка

1. Клонировать репозиторий и подключить конфиг ссылкой:

   ```bash
   git clone https://github.com/velkorra/aero.git ~/aero
   mkdir -p ~/.config && ln -s ~/aero/quickshell ~/.config/quickshell
   ```

   Quickshell читает конфиг прямо из репозитория, поэтому обновления приходят через `git pull` без копирования. Если `~/.config/quickshell` уже существует, сначала переименуй его, иначе ссылка создастся внутри старого каталога.

2. Подключить настройки Niri. Файл `aero-shell.kdl` копируется рядом с основным конфигом и подключается одной строкой в самом конце `config.kdl`:

   ```bash
   cp ~/aero/aero-shell.kdl ~/.config/niri/aero-shell.kdl
   echo 'include "aero-shell.kdl"' >> ~/.config/niri/config.kdl
   niri validate
   ```

   Вторую команду нужно выполнить один раз. `niri validate` проверяет, что конфиг читается без ошибок. В файле лежат автозапуск оболочки и `cliphist`, горячие клавиши и правило размытия для rofi.

   Этот файл именно копируется, а не подключается ссылкой: в нём горячие клавиши, которые каждый настраивает под себя, и обновления репозитория не должны их затирать.

3. Убрать из автозапуска Noctalia: у неё своя панель и свой демон уведомлений, а имя `org.freedesktop.Notifications` на шине может занять только один процесс. Noctalia запускается одним из двух способов, проверить стоит оба.

   Строчка в конфиге Niri:

   ```bash
   grep -n noctalia ~/.config/niri/config.kdl
   ```

   Если нашлась строка `spawn-at-startup "noctalia"`, её нужно удалить или закомментировать, поставив в начале `//`.

   Служба systemd (если она не установлена, команда выдаст ошибку, это нормально):

   ```bash
   systemctl --user disable --now noctalia.service
   ```

   То же самое относится к `mako`, `dunst` и `swaync`, если они стоят и запускаются.

4. Положить аватар в `~/.face` (любой формат картинки). Без него в профиле показывается значок пользователя.

5. Перелогиниться или запустить вручную:

   ```bash
   qs
   ```

   При запуске из терминала туда же пишутся ошибки QML.

## Обновление

```bash
git -C ~/aero pull
```

Quickshell сам перечитывает изменившиеся файлы, перезапускать его не нужно. Если после обновления что-то выглядит не так, перезапусти оболочку (проще всего перелогиниться).

`~/.config/niri/aero-shell.kdl` при обновлении не меняется, потому что это твоя копия. Если в репозитории поменялся исходный файл (новый бинд или правило), разницу видно так:

```bash
diff ~/aero/aero-shell.kdl ~/.config/niri/aero-shell.kdl
```

Нужные строки переносятся в свою копию вручную.

Файлы внутри `~/aero/quickshell` лучше не править у себя без необходимости: если та же строка изменится в репозитории, `git pull` остановится на конфликте. Свои правки видно командой `git -C ~/aero status`.

## Переход с установки из архива

Если конфиг уже стоит из архива (каталог `~/.config/quickshell` скопирован, а не подключён ссылкой), достаточно заменить его на ссылку:

```bash
git clone https://github.com/velkorra/aero.git ~/aero
mv ~/.config/quickshell ~/.config/quickshell.bak
ln -s ~/aero/quickshell ~/.config/quickshell
```

После этого нужно перезапустить оболочку (перелогиниться). `~/.config/niri/aero-shell.kdl` трогать не надо: свои бинды остаются как были. Обои, палитра и превью тоже сохраняются, они лежат в `~/.cache/aero-shell/`. Когда всё заработало, `~/.config/quickshell.bak` можно удалить.

## Что где на панели

Сверху вниз:

- **Орб** запускает `rofi -show drun`, меню открывается по центру экрана. Повторный клик закрывает лаунчер.
- **Часы**: часы, минуты, день недели и дата.
- **Центр управления**: профиль с аватаром, аптаймом и версией Niri, кнопки питания, состояние Ethernet, громкость, плеер (MPRIS). Кнопки выхода, перезагрузки и выключения срабатывают со второго клика в течение трёх секунд.
- **Обои**: сетка превью картинок из `~/Pictures` и видео из `~/Videos`. Клик по плитке ставит обои и пересчитывает палитру.
- **Раскладка**: две буквы текущего языка (`EN`, `RU`), меняются сразу при переключении раскладки. Левый клик или колесо вниз включает следующую раскладку, правый клик или колесо вверх — предыдущую.
- **Трей**: кнопка со стрелкой открывает окно со значками фоновых приложений, как скрытые значки в Windows 7. Окно растёт вместе с числом значков, по четыре в ряд. Левый клик активирует приложение, правый открывает его меню, средний выполняет второе действие, колесо передаётся приложению (например, громкость). При наведении рядом показывается название.
- **Воркспейсы Niri** (по центру): высокая светящаяся капсула — активный, круглая бусина — занятый, маленькая точка — пустой. Клик переключает, колесо листает.
- **Буфер обмена**: история `cliphist` в rofi, тоже по центру экрана.
- **Громкость**: ползунок и кнопка mute, колесо над кнопкой меняет громкость.
- **Колокольчик**: левый клик открывает историю уведомлений, правый включает режим «Не беспокоить». Значок показывает число непрочитанных.

Попапы закрываются по Escape, по клику мимо или повторным кликом по своей кнопке.

## Горячие клавиши

Задаются в `~/.config/niri/aero-shell.kdl`, в блоке `binds`. `Mod` — это клавиша Super (Win).

| Клавиши | Действие |
|---|---|
| `Mod+D` | лаунчер |
| `Mod+Alt+V` | буфер обмена |
| `Mod+A` | центр управления |
| `Mod+N` | история уведомлений |
| `Mod+Shift+N` | режим «Не беспокоить» |
| `Mod+Shift+W` | менеджер обоев |

В таблице клавиши по умолчанию. Чтобы поменять клавишу, достаточно исправить её в начале строки и сохранить файл: Niri перечитывает конфиг сам, а обновления репозитория эту копию не трогают. Раз `include` стоит в конце `config.kdl`, эти бинды заменяют более ранние на тех же клавишах (например, стандартный `Mod+D` с `fuzzel`).

Попапы открываются командой `qs ipc call shell toggle <имя>`, где имя — `control`, `history`, `wallpaper` или `tray`. Её можно повесить на любую клавишу или вызвать из терминала. `qs ipc call shell dnd` переключает «Не беспокоить».

Тосты появляются в правом верхнем углу. Клик по карточке переводит в приложение, которое прислало уведомление: Niri фокусирует его окно, а приложению отправляется действие уведомления по умолчанию (обычно оно открывает нужный чат или страницу). Красная кнопка закрывает уведомление без перехода. Критические уведомления висят, пока их не закроют, и показываются даже в режиме «Не беспокоить». В истории клик по карточке работает так же.

Окно приложения ищется по `app-id` из `niri msg windows`: он сравнивается с именем приложения из уведомления. Если приложение называет себя в уведомлениях иначе, чем в `app-id`, окно не найдётся и сработает только действие по умолчанию.

## Как работают обои и цвета

`set-wallpaper.sh <файл>` запускает новый `mpvpaper` и только потом останавливает старый, чтобы не было пустого кадра. Видео крутятся в цикле без звука, картинки показываются тем же `mpvpaper`. Затем скрипт берёт кадр через `ffmpeg`, отдаёт его `matugen` и получает два файла в `~/.cache/aero-shell/`:

- `colors.json` — палитра оболочки. `Theme.qml` следит за файлом и плавно перекрашивает стекло; белый глянцевый блик при этом не меняется.
- `rofi.rasi` — тема лаунчера в тех же цветах.

Путь к последним обоям хранится в `~/.cache/aero-shell/current-wallpaper`. При старте оболочка вызывает `set-wallpaper.sh --restore`, который поднимает `mpvpaper` и пересоздаёт палитру и тему rofi, если их нет или если шаблон в `templates/` новее готового файла (например, после обновления). Пока обои ни разу не выбирались, используется стандартная аква-палитра.

Превью видео создаёт `ffmpegthumbnailer` (запасной вариант — `ffmpeg`) в `~/.cache/aero-shell/thumbs/`; они кешируются и пересоздаются, только если файл изменился. Каталог `~/Pictures/Screenshots` в список не попадает.

Обои можно поставить и из терминала:

```bash
bash ~/.config/quickshell/scripts/set-wallpaper.sh ~/Videos/clip.mp4
```

## Воркспейсы и раскладка

`Niri.qml` читает `niri msg --json event-stream` напрямую через `Process`. Поток при подключении отдаёт полное состояние (воркспейсы и раскладки клавиатуры), а дальше только изменения, поэтому отдельный скрипт-слушатель и опрос не нужны. Если поток оборвался, сервис переподключается через две секунды. Из одного потока берут данные и список воркспейсов, и индикатор раскладки.

Индикатор показывает первые две буквы названия раскладки из Niri: `English (US)` превращается в `EN`, `Russian` в `RU`.

## Трей

Значки приходят из `Quickshell.Services.SystemTray` (протокол StatusNotifierItem). Меню значка рисуется самой оболочкой в стиле Windows 7 по данным приложения: пункты с галочками и переключателями, разделители, недоступные пункты. Вложенное меню открывается на месте текущего, вернуться можно строкой «Назад».

Приложения регистрируются в трее при запуске, поэтому оболочка должна стартовать раньше них. Если приложение было запущено до оболочки и его значка нет, его нужно перезапустить. Приложения со старым протоколом XEmbed (без StatusNotifierItem) в трей не попадают.

## Размытие

Панель, попапы и тосты сами просят у Niri blur по своей форме со скруглением, правила для них не нужны. По умолчанию Niri размывает только обои под поверхностью (режим xray), это дёшево. Чтобы под попапами размывались и окна, раскомментируй блок с `xray false` в `aero-shell.kdl`.

rofi blur не запрашивает, поэтому для него в `aero-shell.kdl` есть `layer-rule`. Если размытие за лаунчером не появилось, посмотри его namespace командой `niri msg layers` при открытом rofi и поправь `match`.

## Настройка

- Папки с обоями: переменные окружения `AERO_PICTURES_DIR` и `AERO_VIDEOS_DIR` (по умолчанию `~/Pictures` и `~/Videos`).
- Ширина панели, радиус скругления, шрифты, прозрачность стекла: `Theme.qml`.
- Вид палитры: в `set-wallpaper.sh` у `matugen` заданы `-t scheme-vibrant -m dark`; спокойнее выглядит `scheme-tonal-spot`.
- Тема и положение лаунчера: `templates/rofi.rasi` (блок `window`, свойства `location` и `anchor`). После правки нужно применить любые обои или перезапустить оболочку, чтобы готовая тема пересоздалась.

## Что проверено

Конфиг писался не на целевой машине. Проверено следующее:

- имена типов, свойств и сигналов сверены с исходниками Quickshell 0.3.2, Niri 26.04, matugen 4.2 и mpvpaper;
- все QML-файлы проходят `qmllint` без синтаксических ошибок;
- виджеты (панель, карточки, центр управления, менеджер обоев, история) загружались и рисовались в Qt 6.12 с заглушками вместо сервисов Quickshell;
- разбор событий Niri проверен на образцах JSON;
- скрипты обоев прогонялись с заглушками вместо `mpvpaper`, `ffmpeg` и `matugen`.

На живой системе не проверялось: слой Wayland (окна, blur, фокус клавиатуры в попапах), реальные сервисы (уведомления, PipeWire, MPRIS), рендер шаблонов настоящим `matugen`, тема rofi, горячие клавиши с `qs ipc`, трей с настоящими приложениями и индикатор раскладки. Если что-то из этого не заведётся, первым делом смотри вывод `qs` в терминале.
